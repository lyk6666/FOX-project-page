# FOX Project Page

Research project page for **FOX: Visual Exploration of Data Fact Outliers**.

FOX organizes data facts into groups with consistent analytical scopes and
combines distribution-based and pattern-based scoring to support interactive
exploration of anomalous facts.

## Project resources

- Project page: https://lyk6666.github.io/FOX-project-page/
- Source code: https://github.com/lyk6666/FOX
- arXiv: https://arxiv.org/abs/2608.08671
- DOI: https://doi.org/10.48550/arXiv.2608.08671
- Paper: available from the project page
- Demo video: available from the project page

## Local development

Use Node.js 24 or later.

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` build the static export and publish it with GitHub Pages.
